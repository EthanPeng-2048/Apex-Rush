# 联机模式设计（v4 索引）

状态：**已实施（M0–M8 主路径）** · 分支 `feat/online-lan` · worktree `../apex-online`
代码：`src/net/**`（协议/传输/发现/会话）+ `src/game/net/**`（预测/插值/代理/LAN UI）。
门禁：`apex-rush --net-selftest`（编解码 + 会话 + 真 ENet socket）与 `--drive-test` 均 0 失败。

---

## 一句话

**主机权威 + 客户端只预测自己的车 + 别人的车按快照插值**——CS2 一类竞技游戏的核心骨架，四件事，没有补丁层。

```
主机（也是玩家）                          客户端 ×N
模拟全部车 240 Hz                        模拟 1 台车 240 Hz（自己的）
裁决 圈/排名/完赛/损伤                     预测 + 回滚校正
  ─── 30 Hz 快照 ───────────────────▶      别人的车：插值 + 只挡不推的碰撞代理
  ◀── 60 Hz 输入 ───
```

| 对象 | 主机 | 客户端 |
|---|---|---|
| 自己的车 | 权威模拟 | 本地预测（输入立即生效） |
| 别人的车 | 权威模拟 | 不模拟；插值位姿 + `mass=0` 碰撞代理 |
| 圈数/排名/完赛/损伤 | **裁决** | 只镜像 |

## 三个数字

| 指标 | 值 |
|---|---|
| 我的车：操控响应（均/p95） | **≈19 / ≈36 ms**（与同帧率单机差 ≤2 ms，A5） |
| 别人的车：视觉延迟 | RTT/2 + 插值缓冲（LAN 约 25–50 ms，N-05） |
| 带宽（8 人满房） | 下行 **11.2 KB/s**、上行 **3.0 KB/s** |

## 传什么

| 类 | 内容 | 传法 | 频率 | 尺寸 |
|---|---|---|---|---|
| C0 | 发现 / 握手 / 名单 / 规则 | 可靠 | 事件 | 27–161 B |
| C1 | 输入（轴 + 按钮 + 边沿计数 + ack） | 不可靠 + 3 帧冗余 | 60 Hz | 22 B |
| C2 | 快照（8 车 + 自车全状态块 + 相位/时钟） | 不可靠 sequenced | 30 Hz | 345 B |
| C3 | 事件（圈/完赛/结算/损伤/复位/名单） | 可靠有序 | 事件 | 4–91 B |

不传：赛道几何、碰撞体、车辆参数常量表、别人的慢变状态、客户端成绩 → 用 `buildSig + mapHash` 校验代替。

## 九条决策（详见 [decisions.md](decisions.md)）

1. **主机唯一权威**——单一权威是删逻辑，不是加层（ADR-01）。
2. **只预测自己的车**，回滚重放未确认输入（ADR-02）。
3. **别人的车插值 + 只挡不推的碰撞代理**：能撞到、穿不过，但本地永远不会"算出第二个作者"（ADR-03）。
4. **M0 给 `Vehicle` 加 `SaveState/RestoreState`**——回滚的前提，纯增量（ADR-04）。
5. **手写位打包**，定长报文 + 尺寸断言，零新依赖（ADR-05）。
6. **输入三条**：电平 + 3 帧冗余 + 翻转量单调计数（ADR-06）。
7. **发现层自写 Winsock 广播 + 主动查询**（ADR-07）。
8. **规则只由主机裁决**（ADR-08）。
9. **范围**：不做 AI / 中途加入 / 重连 / 手动 IP / 文本输入（ADR-09）。

## 被删掉的东西（[decisions.md](decisions.md) 附录有完整原因）

输入复制给所有人 · 共享输入时间线（tick 软同步）· 远端车本地模拟与单向拉回 · 冲击同步事件与冲量去重 · 误差死区/限幅阈值。
它们都是"每台机器都模拟所有车"这个前提派生出来的补丁；换成单一权威后，这些问题不存在，不需要补丁。

## 运行方式（已实现）

主菜单 → `LAN RACE` → `HOST RACE`（生成房间）/ `JOIN RACE`（4 位码 → 房间列表 → 加入）。
房主在大厅按 `START RACE`（≥2 人）开始；比赛中 `ESC` 为"离开房间"。

命令行（自动化 / 无面板启动）：

| 参数 | 说明 |
|---|---|
| `--net-host <code>` | 直接开房 |
| `--net-join <code> [ip]` | 直接加入（默认 127.0.0.1） |
| `--net-auto` | 大厅凑齐 2 人自动开赛 |
| `--net-seconds <n>` | n 秒后自动退出（联调） |
| `--net-selftest` | 协议 + 会话 + 真 socket 自检 |

`config.rushconf` 的 `[net]`：`player_name` · `game_port`(51230) · `discovery_port`(51231) ·
`snapshot_hz`(30) · `input_hz`(60) · `interp_buffer_ms`(40) · `max_players`(8) · `autostart_race`。

> 端口默认避开 Windows 动态保留段（45xxx–46xxx 段在装了 Hyper-V/WSL 的机器上 bind 会失败）。
> 若端口冲突，改 `[net] game_port` / `discovery_port` 即可。
